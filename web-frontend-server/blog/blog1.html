A first look at cloud computing

The essential building blocks behind services that are ready when you need them.

MYMINICLOUD JOURNAL5 MIN READ

Cloud computing is a way to access computing resources over a network when you need them. Instead of buying and maintaining every server yourself, you can provision compute, storage, and networking as services.

Think in building blocks

A cloud platform is easier to understand when you break it into a few core parts. Compute runs applications. Storage keeps files and data. Networking lets services communicate with each other and with users. Identity and monitoring help keep the whole system controlled and observable.

In this MiniCloud, Docker Compose brings those building blocks together on one network so each service can be developed and operated independently.

Why it matters

On-demand resources make it faster to experiment, scale a service, or recover from a change. The key idea is treating infrastructure as a set of services you can configure and combine to meet a need.
